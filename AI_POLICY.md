# AI Usage Policy

AI-assisted contributions are welcome under these rules:

- **You are the author.** You understand, tested and can explain every line you submit.
- **Disclose.** Tick the AI box in the PR template and name the tool. A `Co-Authored-By` trailer is fine.
- **No unreviewed output.** PRs, issues or comments that look like unedited AI output get closed.
- **No secrets or private data** in prompts that include repository content you don't own.
- **Licensing.** Do not submit generated code you suspect reproduces incompatibly licensed code.

AI agents working in this repo follow [AGENTS.md](AGENTS.md).
